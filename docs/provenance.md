# Provenance

## Original material

Skill prose, state-management code, hand-authored SVG objects and example compositions are original repository materials. They are covered by the repository's MIT license. The visual methods describe general authoring judgments; the four distributable examples use independent, public subjects. No institutional branding, portraits or private source documents are distributed.

## Technical explanations

The ANC example uses [Bose's explanation of noise cancellation](https://www.bose.com/stories/how-do-noise-cancelling-headphones-work) and [Bose's ANC overview](https://www.bose.com/stories/what-is-active-noise-cancellation) for the mechanism and limits. The camera example uses the contrast-detection discussion in [Canon's autofocus article](https://www.usa.canon.com/learning/training-articles/training-articles-list/canon-autofocus-series-dual-pixel-cmos-af-explained). Accessed 2026-09-11. Diagrams are original explanatory constructions, not copied product images or measurement results. Sources also appear beside each slide and in the exported notes.

Business figures are explicitly fictional assumptions. The teaching example uses exact binary threshold-question counts, not measured software performance. Example notes identify simplifications and evidence boundaries.
