# 下载与使用

这是由 `npm run package` 生成并验证的公开交付包；可编辑源码以 [skill 目录](../skills/html-presentation-craft/SKILL.md) 为准。GitHub 文件页面右侧的下载按钮可保存 ZIP。

- [html-presentation-craft.zip](html-presentation-craft.zip)：完整可安装 skill，含指南、starter、四套场景源码、依赖锁文件和创建脚本。将包内 `html-presentation-craft` 目录放入你的工具支持的 skills 目录。
- [presentation-craft-examples.zip](presentation-craft-examples.zip)：四套可观看的演示。先读 `开始阅读.md`，每个主题目录的最终入口均为 `演示.html`。
- [SHA256.json](SHA256.json)：这两个 ZIP 文件的 SHA-256；包内另有逐文件清单。

观看演示不需要安装 Node。浏览器若限制本地 HTML，可以使用静态 HTTP 服务。复制 skill 后制作新演示需要 Node 和 npm，首次安装开发依赖需要网络。验证范围、浏览器与打印限制见 [验证记录](../docs/verification.md)。
