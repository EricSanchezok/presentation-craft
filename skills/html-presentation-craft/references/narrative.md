# 任务与叙事

## 从目标组织材料

先写出受众起点与预期变化。区分需要补充的知识、需要改变的判断、需要掌握的操作，以及希望建立的感受或记忆。根据这个差距选择材料，避免按原始文档目录或工作发生顺序直接分配页面。

把材料分成必要前提、主要内容、支撑证据和可选细节。现场讲述把辅助解释放入讲稿；独立阅读把必要连接留在页面；互动场景预留观众作答和讨论的时间。

涉及事实性主张时，区分事实、推断、假设与目标。核查重要数据和引言的来源、时间及上下文，标明转述或翻译。证据不足时调整主张的强度，或明确给出待验证问题。

## 根据理解任务选择顺序

| 观众需要完成的任务 | 组织依据 | 决定顺序的关键 |
|---|---|---|
| 在选项间作出判断 | 决策标准、可比证据、取舍与行动 | 先给推荐是否会提高讨论效率，还是需要先建立共同标准 |
| 理解陌生概念或机制 | 熟悉的参照、必要组成、关键关系、边界 | 哪个前提缺失会导致下一步被误解 |
| 接受或质疑一个观点 | 主张、依据、替代解释、不确定性 | 证据能支持多强的结论，主要反对意见是什么 |
| 学会方法 | 前置知识、示范、预测、练习、反馈与迁移 | 何时让观众自己做，比继续讲解更有效 |
| 理解进展或变化 | 目标或基线、差异、原因、影响与下一步 | 哪些变化需要解释，哪些只需记录 |
| 跟随经历或建立感受 | 视角、情境、细节、转折、呼应 | 怎样安排信息与情绪的节奏，结尾留下什么 |

选择并组合这些组织方式，不必把每一行变成固定页面顺序。跨页连接可以是因果、时间、比较、主题递进或有意的反差。若过渡难以讲清，检查是否缺少前提、跳过层级或混入无关分支。

## 分页与标题

按一个可完成的理解任务划分页，而非按字数平均切分。内容密集时先判断能否删减、移到讲稿或分步展示，再决定是否拆页；证据需要同时比较时尽量放在同一画面。

标题可以承担结论、问题、定位或章节转折。选择能帮助观众进入当前内容的形式：结论式标题适合明确判断，问题式标题适合预测与探索，简短定位适合图像叙事或复杂证据页。页面正文提供依据或体验，避免只把标题换一种说法重复一遍。

## 语言与讲稿

直接表达作者的判断，用与证据相称的确定程度。保留能提升精确度的术语，并在首次需要时解释；避免用模糊代称替换专业概念。把条件贴近所限制的结论，减少机械主语、口号和无作用的铺垫。

使用类比前确认受众熟悉参照物、对应关系准确；类比引出理解后回到实际内容。需要证明的结论仍由证据或推导支撑。解释性、探索性、叙事性演示使用相应语气，不强制每一页都进行说服或宣言。

讲稿补充转折、解释、提问和强调，不逐字朗读屏幕。估算用时包含观察图、操作与停顿，交付前按实际讲述校准。超时时先删支线和冗余表达，保留论证或学习过程中的必要连接。
