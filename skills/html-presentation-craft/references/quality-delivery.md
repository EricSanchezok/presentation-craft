# 质量与交付

## 选择验收范围

按本次修改验证受影响的内容：文案调整检查含义、换行与字形；构图和步骤调整检查相关完整状态；播放或打包逻辑变化检查实际行为。新演示进行完整验收，定点修改沿用仍然有效的证据。

| 层次 | 检查目标 |
|---|---|
| 表达与内容 | 是否完成受众需要的理解、判断、学习或体验；标题、视觉和讲稿是否一致；事实与证据是否准确 |
| 视觉 | 在整套缩略图及关键完整画面中检查重心、阅读路径、密度、语义换行、标注、尺度与素材处理 |
| 时间与互动 | 逐步前进、回退、直接进入、打断恢复；信息揭示是否便于跟随，思考与操作时间是否充分 |
| 运行与可访问性 | 实际使用的控制功能、键盘焦点、减少动态效果、控制台与素材加载 |
| 观看条件 | 目标尺寸和观看距离，以及预期的其他窗口或设备；需要静态版时检查实际打印或导出结果 |

现场演讲通过计时讲述检查节奏，独立阅读通过脱离讲稿阅读检查连接。不要把源码存在、构建通过、元素未越界或截图数量当作可理解性的证明。

## 检查离线与封装

要求离线播放时，内嵌运行需要的脚本、样式、字体、图片和数据；来源超链接可以按需联网打开。大型视频或在线演示有额外依赖时，明确其交付方式。

检查最终文件的资源引用与实际网络行为，在目标浏览器中验证打开、刷新、导航与素材显示。按交付入口区分本地文件和 HTTP 行为；环境不支持某项检查时记录限制。打包后解压到新目录，确认入口、文件版本和素材完整。

## 交付给接收者

提供一个清楚的最终 HTML 入口；使用包内底座时为 `演示.html`。按用途配套讲稿、使用说明、来源与许可、验证记录，按要求提供源码。说明如何打开、操作与进入全屏，并列出已知限制。源码包排除依赖缓存、无关版本和本机私有配置。

验证记录写明对象版本、环境、操作与观察结果；分别标注结构检查、实际运行和视觉评审。仅估算时长就写估算，未执行的浏览器、文件协议或打印检查不记为通过。
