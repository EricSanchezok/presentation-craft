# 视觉设计案例（参考）

这些案例解释判断方法；示例题材、配色和三页结构不构成模板限制。可运行源码和创建命令见 [示例目录](../assets/examples/README.md)。

## 从对象到场景

先问“这件事发生在什么对象上”，再画对象。保留能辨认身份的轮廓，以及解释本页机制必需的内部结构。耳机需要头梁与耳罩，主动降噪剖面还需要麦克风和扬声器；相机外观需要镜头与机身，解释对焦时则需要镜片、光路与感光面。精度服务理解，不追求零件数量。

在分镜里写下对象清单、结构关系、变化变量和固定参照。再把每个步骤的对象位置、形状、连接、标签与强调写成完整状态。最后用不熟悉领域的听众视角确认：即使暂时遮住标题，这张图是否还透露了正确的对象和关系？这是一种诊断，不要求任何图都脱离语言自明。

| 层次 | 解决什么问题 | 示例 | 适用边界 |
|---|---|---|---|
| 小图标 | 快速识别局部含义 | 申请附件、等待时钟、完成勾选 | 不能靠三枚图标解释复杂机制 |
| 有状态的对象 | 看见同一个对象发生变化 | 镜片位置、图像模糊、候选卡片 | 保持对象身份和固定参照 |
| 机制场景 | 看见部件如何协作 | 耳罩剖面、成像光路 | 连线、方向和局部结构必须准确 |
| 数据图 | 比较数量及不确定性 | 同尺度耗时条 | 比例、单位、来源优先于造型 |

## 声学：把看不见的过程连回实物

耳机示例先用完整外观建立识别，再用局部放大进入耳罩；下一页以剖面解释采集、计算、发声，最后把声压图连接到耳边这个测量位置。三页中的视觉尺度变化服务讲述顺序。

声波弧线只表示传播，不能当成测量结果。波形图明确标注“示意”，理想零线与实际残余同时保留。主动降噪的限制出现在结论与讲稿里，不让漂亮的平直曲线暗示绝对静音。

## 光学：联动的是因果关系

相机示例保持同一幅取景，只改变清晰程度。剖面中的镜片、会聚光线、焦点和图像细节由同一个步骤驱动；感光面保持固定。只移动镜片而保留旧光路，会让动画表达错误机制。

对比度搜索图中，镜头位置、图像清晰度、游标和曲线上的点同步变化。页面限定为对比度检测，不拿这一种搜索过程代表所有自动对焦方法。曲线是定性示意，没有伪造测量单位或性能收益。

## 业务：实物语义与数量精度可以共存

申请页上方的文件、附件和时钟解释等待发生在什么过程中，下方同尺度条形图回答等待占多少。对象绘制不承担时间比例，图表承担时间比例；两者的职责要清楚。方案对比保留统一零点和刻度，结尾用随机分组示意图将建议落实为可验证的试点。

## 教学：让观众操作候选空间

数字卡片是候选对象，区间括号表示当前搜索范围，分界指针标出本轮阈值；四步路径条保留已完成的判定。它们共同解释“排除一半”。打印不能只剩数字 11，必须同时保留它如何被确定的过程。

## 常见失误与修正

| 可见问题 | 理解成本 | 修改方向 |
|---|---|---|
| 大字与箭头散落在几个角落 | 观众需自行补关系 | 先建立主对象，再组织空间与因果路径 |
| 只有矩形，没有可识别对象 | 场景过于抽象 | 选择有用的轮廓和结构细节，不堆装饰图标 |
| 对象动了，连线或标签停在旧位置 | 画面在解释错误状态 | 用一个步骤驱动全部相关目标 |
| 标题被挤成孤立的两三个字 | 语义阅读被截断 | 先改写或重构文字区域，再微调字号 |
| 所有信息一次出现 | 听众无从建立顺序 | 按理解依赖揭示，每步保留完整画面 |
| 打印只保留最后一个答案 | 推导线索消失 | 单独设计静态全过程 |

彩色照片、留白多少、几列构图、是否使用深色背景都取决于场合。复用的是这些判断，不是把某次成功的视觉选择写成普遍禁令。
