# 构图与排版（参考）

## 视觉方向

从受众、场合、主题和给定参考中提取约束。先描述字体角色、颜色含义、画面密度、主要构图与一个能够体现主题的视觉特征，再开始组件细节。学术感不等于极客终端，设计感也不等于艺术海报。

同一套演示使用一致的标题层级、安全边距、出处位置和强调规则；不同页面根据解释任务改变构图。采用对称、非对称、全幅图、比较或逐步构建，应有阅读上的理由。

## 稳定舞台与阅读路径

现场播放默认 16:9 等比缩放，空余空间留在舞台外。先在目标投影尺寸设计，再检查较小窗口；不要因窗口变窄把双栏图重排成网页长列表。竖屏分享或独立阅读是不同消费模式，应单独设计。

每页先明确第一视觉焦点，随后两三个阅读落点。用空间邻近把解释与对象归组，让标题、图和结论产生可理解的联系。留白用于隔离层级和控制密度，不是将信息随意放进几个远角。

用设计变量管理语义颜色和字号。起点可采用约 6% 水平安全边距、三档文本层级，但需按投影与内容检查，不能变成硬编码模板。注释若现场需要读懂，就不能仅因它是“注释”而缩得很小。

## 中文与混排

标题按语义组织，避免谓语、数量单位或专有名词被孤立到下一行。顺序：精炼句子 → 调整文字区域与图文比例 → 选择有意的语义断行 → 小幅调整字号。不要全局 nowrap，也不要用大量 br 修补窄容器。

中文正文使用适合屏幕的字重与行距，英文缩写、数字、单位和公式保持基线与视觉大小协调。不要对中文一律大幅字距。字体字重必须有真实字形，检查缺字与浏览器回退；自托管子集要覆盖最终文案，后续改字后重新检查。

## 照片与装饰

裁切先保全身份与动作，再让视线方向、主体位置服务构图。黑白可用于历史档案或有意的视觉语言；鲜活人物介绍若出现纪念照联想，就应调整。配色、阴影、渐变与纹理只有在层级或主题需要时使用，没有统一的禁用清单。

## 评审动作

先看全套缩略图，检查节奏和重复构图；再逐页看首态、重点态和完成态。追踪视线能否按讲述顺序移动。检查换行、基线、线端、标签、图形尺度、素材裁切。边界检测通过后仍需实际画面评审。
